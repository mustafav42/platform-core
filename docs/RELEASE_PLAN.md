# CherryHouse POS — Release Candidate Plan

Hedef: İlk müşteri kurulumları için stabil bir POS Release Candidate çıkarmak.

## Özellik Dondurma
Release Candidate tamamlanana kadar yeni büyük özellik eklenmez.

## Öncelik
1. Sipariş akışı
2. Tahsilat akışı
3. Yazıcı/KDS
4. İş Günü
5. Yetkiler
6. Gün Sonu/Rapor
7. Kurulum/Yedekleme
8. UX bugfix

## Tamamlanma Tanımı
Bir akış ancak canlı benzeri testte baştan sona sorunsuz çalışıyorsa tamamlanmış sayılır.
